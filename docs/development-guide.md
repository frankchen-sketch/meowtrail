# MeowTrail 开发指南 — 基于哥飞建议

> 核心原则：**截图丢信息，源码/规则才能喂对 AI。三件事分开治。**

---

## 一、关卡逻辑：用规则描述，不用截图复刻

### 问题
喂截图让 AI「抄」 → AI 只能猜规则 → 猜错全错。

### 正确做法
**规则用文字精确描述，让 AI 当「生成器」不是「复刻器」。**

### Meow Block 的规则描述

```
游戏名：Meow Block（矩形分割拼图）

规则：
1. N×N 网格，部分格子有数字（1-9）
2. 玩家在白格上拖拽画矩形
3. 矩形面积 = 包含的数字值
4. 一个矩形只能包含一个数字（但不一定要以数字为起点）
5. 矩形之间不能重叠
6. 所有格子必须被恰好一个矩形覆盖（无遗漏）
7. 胜利条件：网格被完全填满

算法需求：
- 求解器：回溯法，给定数字位置 → 求所有合法矩形分割
- 唯一解校验：求解确认只有一解（或多解标记）
- 难度分级：按推理步数分 easy/medium/hard
- 关卡生成器：随机放置数字 → 求解校验 → 确保可解 → 输出 JSON
```

### 输出格式

```json
{
  "level": 4,
  "grid_size": 5,
  "numbers": [
    {"value": 3, "row": 1, "col": 3},
    {"value": 6, "row": 1, "col": 5},
    {"value": 4, "row": 2, "col": 1},
    {"value": 6, "row": 3, "col": 4},
    {"value": 2, "row": 4, "col": 5},
    {"value": 4, "row": 5, "col": 2}
  ],
  "unique_solution": true,
  "difficulty": "easy"
}
```

## 二、UI：提取设计 Token，不用截图猜

### 问题
截图把设计 token 全丢了 — AI 猜不出圆角是 8px 还是 16px、主色是 #FF6B6B 还是 #FF5A5F。

### 正确做法
**喂竞品 CSS 源码 → 提取精确设计 token → 用 token 生成界面。**

### Token 提取 Prompt

```
分析以下 CSS，提取这个游戏界面的「设计系统」：
- 主色/辅色/背景色（精确 hex 值）
- 圆角（px）
- 阴影（具体参数）
- 字体栈、字号、行高
- 间距体系（8px 网格？）
- 边框样式
然后基于这套 token，帮我设计一个同风格的[猫主题逻辑谜题]界面。
```

### 提取源
- 竞品网站 CSS（用 fetch_page 抓源码）
- 不是截图，不是截图，不是截图

## 三、审美：配色 + 素材，5 分钟搞定

### 事实
- 手游买量小游戏 UI「几乎没啥设计，或者说，好丑」，但「潜在用户对 UI 的追求并没有那么高」（哥飞 2025-03-06）
- 但「稍微花心思打磨一下 UI，整个网站品质就不一样了，付费率都能提升不少」（哥飞 2025-04-15）

### 猫主题游戏的审美捷径
它不靠手绘，靠「配色 + 素材」：

1. **配色**：让 AI 出马卡龙色板
2. **猫图标**：AI 生图 5 分钟（已生成 6 个 ✅）
3. **字体**：换圆体

### 配色迭代闭环（SGAMER 2025-10-10）

```
GPT 生成配色 → 截图回传 → 提修改意见 → 再改 → 2-3 轮够用
```
