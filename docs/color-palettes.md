## UI 组件规范

### 1. 按钮

```
┌─────────────────────────────────────┐
│  主按钮 (Primary)                    │
│  背景: 强调色 | 文字: 白色 #FFFFFF    │
│  圆角: 12px | 内边距: 12px 24px      │
│  hover: 强调色亮度 -10%              │
│  阴影: 0 2px 8px rgba(0,0,0,0.08)   │
├─────────────────────────────────────┤
│  次按钮 (Secondary)                  │
│  背景: 辅色 | 文字: 文字主色          │
│  边框: 1.5px solid 文字辅色           │
│  圆角: 12px                         │
├─────────────────────────────────────┤
│  禁用 (Disabled)                     │
│  背景: #E0E0E0 | 文字: #BDBDBD       │
│  无阴影 | cursor: not-allowed        │
└─────────────────────────────────────┘
```

### 2. 卡片（关卡选择/结果面板）

- **背景**: 辅色，带微弱 `backdrop-filter: blur(10px)` 毛玻璃效果
- **圆角**: 16px
- **阴影**: neumorphic 双阴影 — `4px 4px 12px rgba(0,0,0,0.06), -4px -4px 12px rgba(255,255,255,0.8)`
- **内边距**: 20px
- **标题**: 文字主色，font-weight: 600
- **正文**: 文字辅色

### 3. 游戏网格格子

```
尺寸: 响应式，最小 36px × 36px
背景: 网格背景色
边框: 1px solid 网格线色
圆角: 6px
间隔: 2px

状态:
  ┌─ 默认 ─── 背景: 网格背景色
  ├─ 悬停 ─── 背景: 辅色, 微阴影
  ├─ 选区中 ─ 背景: 选区高亮色, 边框: 强调色 1.5px
  ├─ 已锁定 ─ 背景: 对应猫脸主色, 内含猫脸图标
  └─ 错误 ─── 背景: 错误色 20% 透明, 边框: 错误色
```

### 4. 数字字体

- **数字显示**: `font-family: 'Fredoka', 'Nunito Rounded', sans-serif`
- **数字颜色**: 文字主色
- **数字大小**: 
  - 小数字（提示标记）: 12px, font-weight: 400
  - 大数字（计分/计时）: 28px, font-weight: 600
  - 关卡数字: 48px, font-weight: 700, 带 `text-shadow: 0 1px 2px rgba(0,0,0,0.1)`

### 5. 猫脸方块颜色映射

猫脸方块是核心游戏元素，每种颜色对应一个角色/技能：

| 猫脸 | 色值 | 网格底色映射 | 角色描述 |
|------|------|-------------|----------|
| 💜 紫猫 | `#C9B1F0` | `#F0EBF8` | 俏皮的万能猫 |
| ❤️ 红猫 | `#FF756D` | `#FFF0EE` | 火爆的战斗猫 |
| 💛 黄猫 | `#FCE883` | `#FFFAEB` | 阳光快乐猫 |
| 💙 蓝猫 | `#A2D2F5` | `#EBF4FF` | 安静的智慧猫 |
| 🧡 橙猫 | `#FFC078` | `#FFF5EB` | 温暖的治愈猫 |
| 💗 粉猫 | `#FFB3C6` | `#FFF0F5` | 可爱的惊喜猫 |

> 每个猫脸方块占据网格格子时，格子背景变为对应「网格底色映射」，形成柔和的色彩区域。

## 动效与反馈色

| 事件 | 效果 | 色值 |
|------|------|------|
| 拖拽开始 | 轻微放大 1.05x + 阴影加深 | — |
| 选区拖拽中 | 半透明填充 | 选区高亮色 60% opacity |
| 正确放置 | 弹跳 + 粒子散射 | 成功色 |
| 错误放置 | 抖动 + 闪烁 | 错误色 |
| 关卡完成 | 全屏庆祝粒子 | 渐变: 紫→粉→黄 |
| 猫咪互动 | 眨眼/摇尾巴 | 使用对应猫脸主色 |

## 使用建议

1. **默认推荐方案 A（马卡龙）** — 最柔和治愈，与现有资产完美匹配
2. 方案 B 适合偏成熟温暖的风格变体
3. 方案 C 适合更年轻活泼的风格变体
4. 可通过 CSS 变量实现主题切换：

```css
:root {
  --color-bg: #FFF8F0;
  --color-surface: #E8DFF5;
  --color-accent: #FFB3C6;
  --color-success: #B8E8C0;
  --color-error: #FF756D;
  --color-text: #3D3D3D;
  --color-text-secondary: #9E9590;
  --color-grid: #F0EBE3;
  --color-grid-line: #E0D8CC;
  --color-selection: #FFD6BA;
}
```
