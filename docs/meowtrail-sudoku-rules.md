# MeowTrail — 数独猫游戏规则（待开发）

> 开发商：Oakever Games
> 状态：规则确认中，未开始开发

---

## 游戏类型
类数独逻辑谜题，猫主题

## 棋盘
- N×N 网格
- 部分格子有**立方体箱子**，显示数字 1-9
- 数字 = 该箱子**周围 8 格**中有几只猫

## 操作
- **双击**空白格子 → 放一只猫
- 猫把**整行 + 整列**渲染成猫的颜色
- 每个被染色的格子留下一个**爪印**
- 箱子上的数字**不变**，不提示剩余

## 结算
- 所有猫放完后，猫会**动起来**（动画）

## 猫资产
- 全身 3D 风格角色（非平面图标）
- 坐姿正面、kawaii 风格
- 多种颜色（已知：紫色猫）

## 与 Meow Block 的区别

| 维度 | Meow Block | MeowTrail |
|------|-----------|-----------|
| 类型 | 矩形分割拼图 | 类数独逻辑 |
| 操作 | 拖拽画矩形 | 双击放猫 |
| 数字含义 | 矩形面积 | 周围8格猫数量 |
| 反馈 | 格子变色+猫脸 | 整行整列染色+爪印 |
| 猫资产 | 平面猫脸图标 | 全身3D角色 |
