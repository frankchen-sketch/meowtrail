## 长描述（EN）
MeowTrail is a free browser-based Akari (Light Up) logic puzzle game with a charming cat theme. Players place light bulbs on a numbered grid, illuminating every empty cell while ensuring no two lights shine on each other and each numbered wall has exactly the right number of adjacent bulbs. The game features 20 pre-built levels across multiple difficulty tiers, a daily challenge system with streak tracking and achievement badges (3/7/14/30 day milestones), and an online solver for when you get stuck. Built with Astro and deployed on Cloudflare Pages, it runs fast and smooth on any modern browser. The cute clay cat mascots and warm color palette (purple, apricot, mint) make it inviting for puzzle lovers of all ages.
